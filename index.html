GUIDE

How Channel Control works

01 · GET STARTED

Connect and authorize

Use a slot's Connect button to name the Twitch account and create its isolated Chrome profile. Use Authorize to sign in through Twitch and save the chat permissions securely on this computer.

Repeat those steps for each account slot you want to use.

02 · CHANNEL SESSIONS

Join and leave channels

Join asks for a channel name, connects the account to Twitch chat, and opens that channel in the matching Chrome profile. Part leaves the IRC chat connection. Open opens the saved channel again without changing the connection.

03 · PROFILE STATS

Monitor channel points

Profile Stats shows each connected account's channel, authorization state, and monitor status. Set up monitor opens the account profile and provides the unpacked extension folder. After the extension is loaded in Chrome, reload Twitch to send visible points updates to this app.

The monitor reads what Twitch displays in the browser. It does not collect or redeem points.

05 · SETTINGS

App behavior

Minimize to Windows tray keeps the app running when its window is closed. Use the tray menu to reopen the app or quit it completely.

Account names, channels, and settings are cached locally. OAuth tokens are stored using Windows secure storage.

06 · STATUS

Reading the interface

Connected means the slot is configured. In channel means its IRC session is active. IRC Dashboard contains chat activity, connection states, and controlled manual messages. Diagnostics reports general app errors and clears itself hourly.

07 · IRC DASHBOARD

Advanced chat workspace

IRC Dashboard is an optional advanced section for accounts currently joined to Twitch chat. Each joined account gets a status card, while accounts watching the same channel share one chat location and duplicate messages are removed.

Use Send as account to choose one account for a manual message. Use Chat location to focus one channel. Message filter can show all visible chat, mentions, bot commands, visible redemption-related events, or system events such as PART and NOTICE.

Slow log is enabled by default. During a message burst it shows one warning and suppresses repeated feed entries until chat quiets down. It does not change Twitch slow mode or stop IRC receiving messages.

STEP-BY-STEP

Detailed setup guide

1. Connect an account

Open Accounts, choose a slot, and press Connect. Enter the Twitch username and accept the suggested browser profile name. A separate Chrome profile is created for that slot.

2. Authorize the account

Press Authorize on the same slot, enter the Twitch Client ID, and open the authorization page. Sign in as the matching Twitch account. The token is stored securely on this computer after Twitch redirects back.

3. Join a channel

Return to Accounts and press Join. Enter the channel name without the URL. Join creates the IRC chat connection and opens the channel in that slot's isolated Chrome profile. Part ends the chat connection.

4. Install the Channel Points monitor for each profile

The extension must be loaded separately in every Chrome profile because Chrome stores extensions per profile.

  1. Open Profile Stats and press Set up monitor on the account you want to configure.
  2. Let the account's isolated Chrome profile open. The app also opens the browser-extension folder in File Explorer.
  3. In that same Chrome profile, open chrome://extensions.
  4. Turn on Developer mode.
  5. Press Load unpacked and select the browser-extension folder shown by the app.
  6. Return to the Twitch tab opened for that account and reload it.
  7. Keep that Twitch tab open. The monitor checks the visible Channel Points value about every five seconds.

Repeat these steps for each account slot. Do not select the extension folder from another profile or another program version.

5. Read Profile Stats

Profile Stats shows the account, browser profile, joined channel, authorization state, and monitor state. Waiting for monitor means no update has arrived. Updated means the extension has sent a reading. A points value may be unavailable when Twitch is not displaying it.

6. Use Diagnostics and Settings

Diagnostics lists errors and connection events. Clear diagnostics removes the visible log. Settings controls whether the app minimizes to the Windows tray. Use the tray menu to reopen or fully quit the app.

7. Use the IRC Dashboard

IRC Dashboard is the advanced chat workspace. Join a channel from Accounts first, then open IRC Dashboard to see the account's IRC status and chat activity.

  1. Use Send as account to choose which joined account sends a manual message.
  2. Use Chat location to view one channel at a time. Multiple accounts in the same channel share that one feed.
  3. Use Message filter to show all visible chat, mentions, bot commands, visible redemption-related events, or IRC system events.
  4. Leave Slow log enabled for busy channels. It collapses sustained bursts into one warning and resumes after the chat quiets down.
  5. Use the x button to clear only the IRC activity feed. It does not part accounts or change Twitch connections.

Manual messages are limited to one selected account and are rate-limited. The dashboard does not broadcast a message across account slots.

Extension troubleshooting

If the card remains waiting, confirm the extension appears as enabled in chrome://extensions, reload the Twitch tab, make sure the tab belongs to the correct account profile, and check that the control app is running. If Twitch shows no points value, the monitor cannot report one.
